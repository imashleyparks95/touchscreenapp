# M8D evidence scope

No artwork/model replacements. Existing original imported and procedural art remains, including M8C accessories; original migration hashes are checked by the audit. Source changes are game-owned combat/AI logic and release/cache metadata.

AI logs are deterministic simulation CPU observations under this execution host load, not rendering benchmarks or measured speedup. Maximum legal armies are 48 per side; slime splits use the existing total-actor limit. Equal armies may produce legal stalemates. Browser JSON/screenshots are actual Babylon/Havok rendered fixture sessions at v6.24.0; their upstream test filenames retain earlier checkpoint names. Four presentation plus four native audits were rerun here. Prior shell/library audits remain prior evidence. Physical controller/touch, Windows/audio and target GPU acceptance remain trials.
