# Milestone 7J original filters and monster art

Eight original facial mesh-deformation functions are authored in `dist/js/media-core.js`; they manipulate actual face-local coordinates and keep original UVs. Existing filter indices/names remain stable. There are 27 choices including Original and Random Face.

`dist/js/media-art.js` adds original canvas body patterns, accent coloring, cheek decorations and chest badges to the existing detailed monster. None defaults preserve old designs. `dist/js/media-polish.js` adds original SVG camera/monster badges and workflow copy. No external image, stock sample, new asset license or remote runtime service was used. All 25 M7D covers and 98 original imported art/vendor hashes/license files remain.

Browser screenshots use isolated test profiles. The photo is authored canvas test imagery labeled LOCAL EDITOR TEST IMAGE, not a tracked live face. Actual face-camera distortion tests use authored landmark fixtures for geometry/UV/finiteness, not physical webcam certification. Physical tracking, media/audio quality and device performance remain user trial work.
