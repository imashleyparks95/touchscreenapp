Original procedural accessories in wars3d-details.js: archer quiver/arrows, slinger pouch, scout scarf and Pulse Ranger chest/core. These are spine-mounted, body-free meshes; no third-party models, replacement source assets or physics bodies were introduced. Existing rig, hand/weapon paths, illustrated purchasing and original 98 asset/vendor hashes remain.

Game-owned wars3d-presentation.js fits actual projected battlefield corners, provides manual troop inspection and calculates distance-driven mounted props and reduced-motion/death wing poses. It is not a new shared toolkit API.

Evidence includes actual Babylon/Havok browser rendering and independent projection/model checks. Browser controller/pointer inputs are fixtures. Battle layout audits pause a legally started battle; live clock and input are checked separately. Physical hardware, audible audio, target GPU rendering and large-army performance remain user trials. Screenshots are generated from the local tested runtime, not physical-device captures.
