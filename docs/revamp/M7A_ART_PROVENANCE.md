# Milestone 7A — original Canvas artwork

`dist/js/reaction-art.js` contains original, locally generated illustrations authored for this repository: moonlit garden/hills/timber/leaves/flowers/dew, beetle shells/limbs/eyes/antennae/marks, twilight festival tents/bunting/clouds/hills/stars, paneled balloon surfaces/strings/knots/faces/armor/spikes and restrained feedback particles. Geometry follows the existing game's target coordinates; color/symbol definitions come from its existing `BUG_COLORS`.

No stock image, remote service, generated binary model, copied character or new third-party asset was introduced. No original asset/vendor/license file or immutable migration checksum was changed. Existing fonts, shared controls, audio synthesis and other games' illustration paths retain their prior provenance. This does not relicense the whole application or its bundled third-party components.

Screenshots use isolated test profiles and actual browser Canvas rendering. Some completion checks force only the rule clock to isolate record persistence; legal full rounds use independent real rules/taps. Physical device certification is separate.
