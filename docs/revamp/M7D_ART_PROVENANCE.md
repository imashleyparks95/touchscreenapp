# Milestone 7D original artwork

All 25 public cover illustrations are original SVG code authored in this repository in `dist/js/cover-art.js`. No remote images, generated image service, third-party replacement assets or additional licenses are used. Each public ID has a separate subject and palette. Contact sheet `M7D_all-covers.png` uses the actual production artwork provider and was visually reviewed.

Original canvas PCB frame/trace and workbench/pegboard detail is in `dist/js/workshop-ui.js`; existing detailed robot drawing remains. All 98 original imported asset/vendor hashes and license files remain unchanged. The private hidden-game artwork is preserved. This covers public launcher/preview/common cover surfaces; it does not claim every in-game asset was redrawn.
